# Subscription Renewal Tracker

A Java command-line tool for tracking subscription costs and renewal dates.

## Project Status

Finished.

## Planned Features

- Add subscriptions with a name, price, billing cycle, and next renewal date.
- View all subscriptions in one place.
- Estimate monthly spending across monthly and yearly plans.
- Show subscriptions that renew within the next seven days.

## Example

| Subscription | Price | Billing Cycle | Next Renewal |
| Music Plan | $12.00 | Monthly | 2027-06-10 |
| Cloud Storage | $60.00 | Yearly | 2027-07-15 |

**Estimated monthly spending: $17.00**  
The yearly plan costs $60 ÷ 12 = $5 per month on average.
